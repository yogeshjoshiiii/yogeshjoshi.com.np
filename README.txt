Yogesh Joshi Portfolio
=======================
Put these files in your website root.

Expected asset:
assets/logo.png  -> browser favicon only.

Important:
- Replace the Google Form URL in contact.html with your existing form URL.
- Replace project data in projects.html with your real projects.
- Do not use the placeholder tool cards if you already have working tools; move your existing tool markup/functionality into tools.html.
- The CSS/JS are intentionally lightweight: scroll reveal, hamburger-to-X, subtle light flash, responsive layout, reduced-motion support.
